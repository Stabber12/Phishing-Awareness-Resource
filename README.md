# Phishing-Awareness-Resource

A cybersecurity awareness project that teaches users how to identify and prevent phishing attacks, The aim is to teach people about phishing and how to avoid, fight and report it.

Objectives 

•	Explain phishing
•	Identify common examples of phishing
•	What might hackers benefit from you
•	How to avoid phishing and respond to it

Who are the targets

•	Students, Employees and internet users

READ phishing-awareness.md to learn more about phishing attacks and security measures
